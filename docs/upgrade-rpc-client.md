# Agent managed upgrade v1 download client

The shared wire package mirrors local Dashboard commit 245a4b104e915a0590018bf96312a2a51a5fbce5, with only the module import path changed. It uses a separate bounded gRPC service and preserves the legacy protocol. The Agent client reuses its existing certificate-validated TLS connection and authentication metadata. It checks a locally provisioned server ID and sequence, streams ordered chunks into a private staging file, verifies archive digest and Ed25519 signature, platform and forward version, and exposes the sealed package. An explicit verification receipt can be sent only on the same Client and while the staged package is open. The acknowledgement is not a grant to install. No executable replacement, automatic polling, production provisioning or final result reporting is wired here.

TLS loopback fixture tests exercise actual downloads, receipts, wrong identity, wrong secret, untrusted key, truncation and replay. Dashboard's separate server test uses real task SQLite and a deliberately enabled loopback proxy test path. Cross-repository live Dashboard tests, installation authorization, durable local reservation integration, result reconciliation and production service wiring remain required. Windows managed upgrade remains disabled.
