The security-regression CI job resolves the module graph using Go 1.27.4, verifies downloaded module content, prints the exact go.mod/go.sum diff if any, runs read-only tests and vet, and checks reachable Go vulnerabilities. The final gate rejects uncommitted module changes. If lock drift is found, review and commit the exact generated dependency changes before qualification. No dependency versions are guessed, and no automated release is triggered. Native Linux and Windows baseline jobs remain unchanged. The scanner uses its latest available version at CI execution; release qualification should record its version and results.
